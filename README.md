# LanXfer 局域网快传（v1.2.0）

借鉴 HybridFileXfer「多连接并行 + 多网卡通道」的思路，从零写的一套：

- **手机端**：Magisk 模块，root 常驻服务，无界面。Magisk 里点模块的「操作」= 开启/关闭服务，并显示令牌和手机 IP。
- **电脑端**：`LanXfer.exe`，Windows 原生单文件程序，免安装、不要 Java。

## 用法

1. Magisk 刷入 `LanXfer-magisk-v1.2.0.zip`，重启（安装日志里会显示令牌）。
2. 双击 `LanXfer.exe` → 「设置」填令牌 → 自动搜索并连接手机。
3. 窗口只显示手机文件：
   - 从资源管理器/桌面**拖进窗口** = 上传到当前手机目录
   - 把手机文件/文件夹**拖到资源管理器的文件列表或桌面** = 下载。松手时 LanXfer 只识别目标文件夹，然后自己多连接直接写盘（FastCopy 式），不弹 Windows 复制窗口；进度和「取消传输」都在 LanXfer 窗口底部
   - 也可以选中后点「下载到…」选文件夹
   - 目标处已有大小、修改时间都相同的文件会跳过（可当增量备份用），不同的会覆盖
   - 双击进入文件夹，Backspace 返回上级，F5 刷新，F2 重命名，Del 删除
4. 关闭窗口 = 缩到右下角托盘；默认 `Ctrl+Alt+F` 全局呼出/隐藏（设置里可改）；托盘菜单或设置里可勾选开机启动。

## 日志（v1.1.0 新增）

- 主窗口「日志」按钮或托盘菜单「日志…」打开日志窗口，可按「连接/断开/重连」「传输」「文件名截断」「错误」筛选，支持复制全部、打开日志文件夹。
- 日志文件：`%APPDATA%\LanXfer\lanxfer.log`（超过 5 MB 自动轮转为 `lanxfer.log.1`）。
- 记录内容：连接时间与耗时、通道数；断开时间、本次连接持续多久、原因；每次重连尝试、重连成功时断开了多久；每次传输的开始/结束、文件数、速度、失败文件；每个被截短或改名的文件「原名 → 新名」。
- 连接每 3 秒检测一次，断线后自动重连（先原 IP，再按设备名在局域网重新搜索，适配手机换 IP）；传输中的分块会自动重试约 20 秒，短暂断网不会中断传输。
- 手机端日志 `/data/adb/lanxfer/lanxferd.log` 也会记录电脑连接/断开时间、令牌错误、文件名过长。

## 文件名过长

- 手机（ext4/f2fs）单个名称最多 255 **字节**，约 85 个汉字；Windows 允许 255 个字符，所以长中文名上传会失败。现在上传时自动截短到 250 字节以内。
- 下载/拖出到 Windows 时单个名称限制 120 字符，整个相对路径限制 200 字符（资源管理器拖放上限 260）。
- 截短规则：保留开头和扩展名，中间加 `~` + 6 位校验码（如 `很长的名字…~3fa21c.mp4`），不同长名不会撞名；同一文件夹在所有子文件里保持同一个短名。
- 所有截短都会写入日志「文件名截断」类别，方便对照原名。

## 小文件为什么快（v1.2.0）

- ≤1 MB 的小文件每 256 个（或 16 MB）打成一批，一次 HTTP 请求连续传，8 条连接同时跑，不再一个文件一个来回。上传、下载都是。
- 拖出不经过 Explorer 的虚拟文件复制引擎（它逐个文件拉取、带慢速进度窗口）。
- 只有拖到资源管理器/桌面以外的程序（比如聊天窗口）时，才走 Windows 自己的拖放，此时只支持文件，不支持文件夹。

## 为什么快、为什么不被杀

- 大文件切 8MB 块，多个 TCP 连接同时传（默认 8 个，设置里可调）；小文件多个同时传。
- 手机有多张网卡（双 WiFi、热点、USB 网络共享、有线）时，每个能连通的 IP 都当一条通道，连接平均分布。
- `/sdcard` 直接读写 `/data/media/0`，绕过 FUSE/MediaProvider 这一层；新文件自动修正属主和 SELinux 标签，媒体文件会通知相册索引。
- 服务由 Magisk 的 root 进程拉起，不是 App，没有后台限制；守护进程挂了 2 秒内自动重启；`oom_score_adj=-1000`；可选 wakelock（息屏不降速）。

## 手机端配置

`/data/adb/lanxfer/config`：端口、令牌、RAW（是否绕过 FUSE）、WAKELOCK、设备名。改完在 Magisk 里点两次「操作」生效。日志：`/data/adb/lanxfer/lanxferd.log`。

## 已知限制（Demo）

- 电脑端是在 Linux 上交叉编译的，没能在真 Windows 上跑过，首次使用如有问题把现象告诉我。
- 拖到资源管理器里某个子文件夹图标上，会放进当前打开的那个文件夹，而不是那个子文件夹。
- 局域网内明文 HTTP + 令牌鉴权，不建议在公共 WiFi 开着服务。
- 只支持 64 位 Windows 10/11。

## 源码结构

- `proto/` 共享协议类型
- `cmd/lanxferd/` 手机端守护进程
- `client/` 传输引擎（并行分块、多通道、流式预读）
- `cmd/lanxfer/` Windows 界面（lxn/walk，托盘、全局快捷键、开机启动、OLE 虚拟文件拖出）
- `cmd/lanxfer-cli/` 命令行客户端（测试用）
- `magisk/` 模块脚本
